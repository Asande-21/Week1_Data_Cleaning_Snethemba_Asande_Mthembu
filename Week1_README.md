# 🧹 Data Cleaning with Python & Pandas

## 📌 About the Project

This project focuses on learning and practising data cleaning using **Python and Pandas**. I am working with a sample applicant dataset containing intentional data-quality issues to simulate the challenges encountered when preparing real-world data for analysis.

The goal is to identify, investigate, and correct these issues step by step while developing practical data science skills.

## 🎯 Project Objectives

- Identify and handle missing values.
- Detect and remove duplicate records where appropriate.
- Investigate inconsistent and incorrectly formatted data.
- Explore data types and correct them when necessary.
- Validate the dataset after cleaning.
- Understand how data quality affects data analysis.

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **Jupyter Notebook / Google Colab**

## 📊 Dataset

The project uses `applicants.csv`, a practice dataset containing intentionally introduced data-quality issues, such as missing values, duplicate records, and other inconsistencies.

The project also includes `applicants_cleaned.csv`, which will contain the cleaned version of the original dataset after applying appropriate data-cleaning techniques.

Keeping both datasets makes it possible to compare the original data with the cleaned data and evaluate the improvements made during the cleaning process.

Both datasets are used for educational purposes to practise data inspection, cleaning, and validation.

## 🔍 My Data Cleaning Workflow

1. **Inspect the data** — Examine the dataset's structure, columns, and data types.
2. **Identify issues** — Check for missing values, duplicates, and inconsistencies.
3. **Investigate** — Determine the nature of each issue before deciding how to handle it.
4. **Clean the data** — Apply appropriate cleaning techniques using Pandas.
5. **Save the cleaned dataset** — Export the cleaned data to `cleaned_applicants.csv`.
6. **Validate** — Recheck the dataset to assess whether the issues have been resolved.
7. **Document findings** — Record the changes made and the reasoning behind them.
