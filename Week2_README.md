# 📊 Week 2: Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** using Python and Pandas to explore an internship applicant dataset. The aim was to identify patterns in application volumes, submission dates, application outcomes, and university representation through data visualisation.

This project builds on the data-cleaning work completed in Week 1 and applies visualisation techniques to make the dataset easier to understand.

## 🎯 Objectives

- Explore the cleaned applicant dataset.
- Identify patterns and trends in application submissions.
- Compare application volumes across different domains and universities.
- Examine application outcomes across the dataset.
- Create clear and informative visualisations to communicate findings.

## 🛠️ Tools and Technologies

- **Python** — programming language used for the analysis.
- **Pandas** — data loading, manipulation, grouping, and analysis.
- **Matplotlib** — creating charts and visualisations.
- **Seaborn** — data visualisation library imported for use in the notebook.
- **Google Colab** — environment used to write and execute the analysis.

## 📂 Dataset

The dataset contains applicant information, including:

- Applicant Name
- Email
- Phone
- Domain Applied
- University
- Application Date
- Status

The cleaned dataset contains 77 applicant records. The analysis explores the distribution of these records across different categories and time periods.

## 📈 Visualisations

Five visualisations were created to investigate different aspects of the dataset:

1. **Number of Applications per Domain** — compares application volumes across the different domains.
2. **Application Trend Over Time (Monthly)** — examines how application submissions vary from month to month.
3. **Overall Application Status Breakdown** — shows the distribution of selected, rejected, and under-review applications.
4. **Application Status by Domain** — compares application outcomes across different domains.
5. **Number of Applications by Day of the Week** — explores differences in submission activity across the days of the week.

Each chart includes an appropriate title and labelled axes where applicable.

## 🔍 Key Findings

- Web Development and Software Engineering recorded the highest application counts, with 20 applications each.
- Application volumes varied throughout the year, with April, June, and July recording 11 applications each. September recorded the fewest, with 2.
- Under Review was the most common application status, accounting for 33 records, followed by Rejected with 23 and Selected with 21.
- Wits recorded the highest number of applications by university, with 20, followed by UKZN with 17.
- Friday recorded the highest number of applications by day of the week, with 14, while Tuesday and Saturday recorded 7 each.
